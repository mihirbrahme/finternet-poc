# Admin Console

Light operational scaffold for Packet 3.

This console is intentionally static for now. It explains the participant and credential setup flow that later packets can replace with live API calls.

Open `index.html` in a browser to review:

- participants;
- participant trust details;
- credential issue/revoke concepts;
- dependency mode labels.

Packet 3 dependency modes:

```text
VC Issuer: LOCAL_MOCK
VC Proof Suite: LOCAL_MOCK
Participant Registry: LOCAL_MOCK
Credential Registry: LOCAL_MOCK
Smart Account Provider: LOCAL_MOCK
OBP Registry: NOT_CONNECTED
EPR Reference: NOT_CONNECTED
```
